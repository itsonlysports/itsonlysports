# Sports blog

A simple sports opinion blog built with Jekyll, a free tool that turns plain
text files into a website. GitHub Pages (free hosting) builds it automatically.

- **To add a post:** see [HOW-TO-ADD-A-POST.md](HOW-TO-ADD-A-POST.md).
- **To change the site name or sports list:** edit `_config.yml`.

## What's where

| Folder / file | What it is |
|---|---|
| `_posts/` | Your blog posts, one file each |
| `_templates/new-post.md` | Copy this to start a new post |
| `about.md` | The About page |
| `_config.yml` | Site name, tagline, list of sports |
| `assets/css/style.css` | Colors and fonts |
| `assets/images/` | Pictures for posts |
| `_layouts/`, `_includes/` | Page templates (no need to touch) |

## Preview on your own computer (optional)

Needs Ruby. Run `gem install jekyll` once, then `jekyll serve` in this folder
and open http://localhost:4000.
